# מתאם מודלים

**[לאפליקציה החיה: modeleiatslacha-gh.vercel.app](https://modeleiatslacha-gh.vercel.app)**
קישור למיזוג האחרון, בלי Vercel: [raw.githack](https://raw.githack.com/Anat1969/ModeleiAtslacha-GH/main/index.html)

אפליקציה שעוזרת לבחור מודל חשיבה לפי הבעיה, ולא לפי הפופולריות שלו.
חמש שאלות אבחון: סוג הבעיה, הסכמה על ההגדרה, שכבת זמן, יחידת ההחלטה ובסיס נתונים.
התוצאה: מודל ראשי, מודל נגדי, תווית אזהרה, שלושה צעדי יישום ושאלת בקרה.
26 מודלים ב-8 תחומי ידע. כל מודל מוצג עם **מקורו האמיתי** ועם **רמת הראיות** שלו. 13 מתוך 26 מיוחסים בדרך כלל לאדם אחר.
כל מודל נלמד באותו סדר: היכרות (הגדרה, תובנה, שיר, סיפור הגילוי), הבנה (שרטוט, הדגמה, דוגמאות) ויישום (מי יישם, מתי מטעה, שאלת בקרה). המקורות בסוף.
בכל דף מוקד גרפי אחד: מרחב אבחון תלת־ממדי, שרטוט מוסבר לכל מודל, וציר הזמן שבין הרעיון לתרשים.

## הרצה
```
npm run serve     # http://localhost:4173
npm test          # לוגיקת ההתאמה ושלמות הנתונים
npm run e2e       # Playwright, במחשב ובנייד
npm run fit       # בגודל המסך: יחס גלילה בארבעה גדלים
npm run glyphs    # בלי טקסט על טקסט בתוך השרטוטים
```

## מבנה
- `data/models.json`: מקור האמת לכל הטקסטים, המודלים וכללי ההתאמה.
- `src/matcher.js`: פונקציית התאמה טהורה.
- `src/app.js`, `src/styles.css`, `index.html`: ממשק סטטי, בלי שלב בנייה. שמירה ב-localStorage.
- `docs/research-status.md`: מה נבדק במקורות ומה לא.

## חשוב לדעת
טבלת ההתאמה היא הערכה שמבוססת על הדוח "מודלי חשיבה בבדיקה", לא תוצאה מבוקרת.

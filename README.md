# מודלים של הצלחה: מתאם מודלים

אפליקציה קטנה שעוזרת לבחור מודל חשיבה מתאים לבעיה: לפי סוג הבעיה, מידת ההסכמה עליה, שכבת הזמן וגודל יחידת ההחלטה.

## מה יש כאן
- CLAUDE.md: הוראות מלאות לבנייה, כולל חמש שאלות האבחון וטבלת ההתאמה.
- docs/: הדוח המחקרי שעליו מבוססת האפליקציה.
- data/models.json: מאגר המודלים (ייווצר בשלב הבנייה הראשון).

## עיקרון מרכזי
לפני בחירת מודל, מאבחנים את הבעיה. כל מודל מוצג עם מקורו האמיתי, רמת הראיות שלו ותווית אזהרה.

## מצב הפרויקט
שלב אפיון. הדוח המחקרי נבדק, אך טבלת ההתאמה היא הערכה ולא תוצאה מבוקרת.
